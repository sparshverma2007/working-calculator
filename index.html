Simple Calculator

A web-based calculator built with HTML, CSS and JavaScript. Use it to add, subtract, multiply and divide, with the on-screen buttons or your keyboard.

0

How to use

  • Click the number buttons, choose an operator (÷ × − +), then press = to see the result.
  • AC clears everything, DEL removes the last digit, and % converts the number to a percentage.
  • Keyboard: digits, + - * /, Enter for =, Backspace to delete, Esc to clear.
  • Dividing by zero shows "Error". Press AC to start again.
